# ADR-003 — Persistence layer

**Status:** accepted<br />
**Date:** 2026-07-15

## Context

The system stores normalized companies, signals, campaigns, and audit events with strong consistency per workspace.

## Decision

Use PostgreSQL 15+ with SQLAlchemy 2.0, asyncpg for application traffic, and Alembic for schema migrations. JSONB columns carry extensible metadata.

## Consequences

Full ACID per workspace, portable SQL, and mature migration tooling. We accept the operational complexity of a relational database over a document store.
