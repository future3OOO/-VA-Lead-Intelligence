# ADR-011 — Observability and runbooks

**Status:** accepted<br />
**Date:** 2026-07-15

## Context

Production incidents must be diagnosable without SSHing into workers.

## Decision

Emit structured JSON logs, expose FastAPI `/health` and `/metrics`, and write operational runbooks in `docs/runbooks/`. Temporal UI provides workflow visibility.

## Consequences

On-call can follow runbooks. Health endpoints are wired into load balancer and Terraform health checks.
