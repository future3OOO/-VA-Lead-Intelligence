# ADR-004 — API and event serialization

**Status:** accepted<br />
**Date:** 2026-07-15

## Context

Contracts must be machine-readable for frontend, downstream consumers, and compliance review.

## Decision

Use FastAPI 0.111+ and Pydantic v2. Event schemas and API DTOs share the same generated Pydantic classes, then are exported to JSON Schema and OpenAPI.

## Consequences

Validation and serialization logic live in one place. OpenAPI and JSON Schema are always aligned with runtime code.
