# ADR-005 — Durable workflow execution

**Status:** accepted<br />
**Date:** 2026-07-15

## Context

Campaign runs, classifier pipelines, and export jobs can be long-lived and must survive process restarts.

## Decision

Use Temporal for durable workflows and activities. Redis supports task queues and rate-limit counters. Temporal provides visibility, retries, and sagas.

## Consequences

Workflow definitions are explicit and versioned. We add infrastructure but avoid ad-hoc cron and fragile retry loops.
