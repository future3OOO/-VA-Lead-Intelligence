# ADR-009 — Multi-tenant authorization

**Status:** accepted<br />
**Date:** 2026-07-15

## Context

Multiple customer workspaces share one deployment, and tenants must not read each other's data.

## Decision

Use `x-workspace-id` and `x-api-key` headers. The `require_workspace` dependency validates the API key and returns the workspace UUID. All queries filter by `workspace_id`.

## Consequences

Row-level tenant isolation is enforced by query filters, not RLS, because asyncpg + SQLAlchemy RLS `SET` statements are complex. This is documented as a deliberate trade-off and tested.
