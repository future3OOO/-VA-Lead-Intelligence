# ADR-010 — Audit and event sourcing

**Status:** accepted<br />
**Date:** 2026-07-15

## Context

Regulators and customers require an immutable record of decisions, exports, and score changes.

## Decision

Append immutable `audit_event` records for every mutation. Domain events carry `event_id`, `correlation_id`, `workspace_id`, and `occurred_at`.

## Consequences

Audit events are insert-only. Deletion is implemented as a `deleted` status with an audit record, never `DELETE`.
